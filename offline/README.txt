TIME MACHINE - OFFLINE COPY (no internet needed)
================================================

This folder is a complete copy of the game. It works with no internet and no Wi-Fi at all.

HOW TO USE IT
1. Unzip the folder (right-click, "Extract all" on Windows; double-click on a Mac).
   Put it anywhere: the desktop, a USB stick, a shared drive.
2. Open the file  start.html  (double-click it). It opens in your browser.
   Use Chrome, Edge or Firefox on a laptop with a keyboard and mouse.
3. Choose how to start (Latin names, light graphics, fights), then press Play.
4. Each student makes a character and plays. Nothing is saved or sent anywhere:
   when the browser tab is closed, the game is forgotten, so every student starts fresh.

THE SAME ON EVERY COMPUTER
After you press Play, copy the address of the game from the browser bar. It ends with
something like  ...index.html?class=Latin&latin=1  and holds all of your choices.
Open that address on each computer to start them all the same way.

OPTIONS YOU CAN ADD TO THE ADDRESS (after  index.html? , joined with  & )
  class=Latin 7        the class name shown at the bottom of the screen
  latin=1              Latin names for ancient Rome
  low=1                light graphics for slow computers
  fights=0             no gladiator fights
  city=rome            rome, delhi, cancun or beijing
  era=ancient          ancient or modern
  at=pantheon          start in front of a sight (its id, e.g. forum, colosseum, pantheon)
  hour=12              start at this hour of the day (0 to 24)
  hunt=forum,pantheon  a scavenger hunt: the students must find these sights

WHAT DOES NOT WORK OFFLINE
  - The teacher's dashboard (watching what each student does) and class codes need the internet:
    use the website for those.
  - Playing against other people, friends and chat.
Everything else works: walking the cities, the shops, the Latin names, the scavenger hunt.

KEYS
  W A S D   walk (Shift to run)       C   change the camera          K   ancient / today
  Q E or the mouse   look around      F   talk, sit, press buttons   G   guide to the nearest sight
  M   the map

The Latin in the game is not checked by a Latin teacher yet: please check it before using it.
